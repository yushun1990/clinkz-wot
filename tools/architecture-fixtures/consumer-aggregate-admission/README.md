# Consumer aggregate evidence fixture

The standalone library in this non-production crate tests composition before admitting
`WP-200-CONSUMER-PROPERTY-READ-AGGREGATE`. Normal dependencies are production
TD/Core/Foundation; TD's `validated-thing` capability is explicit. A dev
dependency reuses only inert execution halves from the historical compiler
fixture. Complete registrations, support capture, callbacks and native/public
Host artifacts are production Core values. No model issuer, copied TD algorithm,
Planning production aggregate or Servient coordinator participates in that library.

The fixed two-coordinate witness runs real validation and both paid semantic
passes, materializes Core logical plans, finishes all real bounds before starts,
and uses the concrete outputs after actual source/registration destruction.
The original non-first Form indices and empty property events are literal test
expectations. The original admission evidence also rejected a later 65-byte
target bound with zero starts; that bounds-first oracle is historical.
Synthetic bound values exercise zero/foreign/over-step/overflow eligibility;
they are not attributed to the production closed compiler.

`InputOwner` models only the consumed loan/drop shape with one fixed artifact.
Its completion and abandonment end actual TD and registration loans. `Slot`
owns one inline destination, commits an actual Foundation guard, and leaves
the original account charged until explicit root release. Undersized rejection
returns the guard; rollback preserves account peak history. Compile negatives
reject raw Thing/compiler and premature source/registration destruction.

The historical library uses ordinary test-side copies and fixed output destruction. It
does not implement general aggregate lookup/preflight/sealing, fallible variable
storage, complete phase work envelopes, variable rollback, exact PlanFootprint,
global capacity provenance or publication. It compares shared logical facts;
the existing Core completion tests own allocator failure/slot release evidence.
It cannot prove that product Planning requests `validated-thing` in its normal
dependency; that manifest correction and isolated graph checks are production
completion obligations. Portable tests execute on the host. ARM checks compile
the normal library only, without its test-side endpoint dependency.

Run with Rust 1.95.0 from the repository root:

```sh
cargo test --locked --offline --manifest-path tools/architecture-fixtures/consumer-aggregate-admission/Cargo.toml
cargo test --locked --offline --manifest-path tools/architecture-fixtures/consumer-aggregate-admission/Cargo.toml --no-default-features
cargo test --locked --offline --manifest-path tools/architecture-fixtures/consumer-aggregate-admission/Cargo.toml --no-default-features --features async
cargo check --locked --offline --manifest-path tools/architecture-fixtures/consumer-aggregate-admission/Cargo.toml --no-default-features --target thumbv7em-none-eabihf
cargo check --locked --offline --manifest-path tools/architecture-fixtures/consumer-aggregate-admission/Cargo.toml --no-default-features --features async --target thumbv7em-none-eabihf
```

Production completion requirements and independent review belong to

Passing this discriminator grants no admission or acceptance.

`tests/aggregate.rs` separately depends on the actual public Planning aggregate.
It exercises both static and public Host output, exact ranges and footprints,
fallible output allocation, capped child ledgers, every public cancellation and
abandonment boundary, and source-free item/byte reclamation. Its fixed allocator
observer is armed after preflight, excluding caller and registration provisioning.
It injects null at every observed request, retains an independent live owner,
and compares physical live/peak/largest requests with output ledger observations.
The original cleanup account remains charged until explicit terminal root release.

The test also includes the exact production source under `cfg(test)` with
`planning/tests/support/consumer_property_read.rs` to observe callback counts,
inject otherwise impossible bounds, and inspect Ready retry allowances. These
observations are distinct from public entry tests; production eligibility remains
sealed to Core's checked complete owners. No test result proves publication or
independent acceptance.

`planning/tests/normal-dependency` has only Planning as a normal dependency and
no dev dependencies. Check it in std, no-default and async cells to prove TD's
`validated-thing` is requested by Planning itself. The ARM checks for that crate
compile the actual public Planning aggregate; the historical fixture's ARM
checks still compile only its narrower library.

`tests/form_metadata.rs` exercises the admitted WP-600 shared amendment using
the production paid TD getter, owned plan scalar and restricted closed compiler.
It covers default Forms, explicit method/header/unknown extensions, response
overrides and present-empty metadata, preserving typed round trips, Ready replay,
rewind and unknown-versus-empty semantics. `tests/aggregate.rs` exercises the
actual Planning propagation and later-coordinate bounds rejection after earlier
pure compilation, funded rollback/retry and allocation failures for static/public Host
complete registrations. Run in the same three feature cells above. These shared
tests supply no HTTP I/O, SDK qualification or independent completion acceptance.

The composition model's all-bounds ordering is historical precursor evidence,
not the current production aggregate. Its later-bounds/zero-start test is retired:
the current shared-source tests and downstream native compiler/runtime probe
exercise sequential compilation, original-owner rollback and zero client effects.
Fixed slot/guard tests remain useful within their original narrower scope.

`tests/open_compiler.rs` is a separate downstream public Planning suite with an
external compiler, 128-byte alignment and native cursor/artifact storage above
64 bytes. It rejects excessive captured callback and combined cleanup costs
before compiler work, and completes at exactly the selected profile caps.
Actual later bounds failure, competing earlier progress/later bounds errors,
invalid artifacts and unpaid progress retain the original output/cursor owners.
It proves no client invocation, source destruction before cleanup, unpaid cleanup
retention, exactly-once abort/destruction, slot occupancy until terminal rollback
and retry under the same original account. It runs in all three cells above;
installed execution is separately covered by the runtime runner's open compiler
suite. Neither suite establishes arbitrary callback honesty or real-wire behavior.
