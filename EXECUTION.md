# Deprecated Execution State Carrier

`EXECUTION.md` is no longer an active project-governance artifact.

Current engineering work is reconstructed from the fetched repository,
`PLAN.md`, the relevant authoritative documents, the active Git branch or pull
request, code, tests, and CI. Task-session planning and model/profile selection
belong to the active conversation and are not persisted here.

This path is retained only because historical review and transition evidence
may reference it as part of an exact repository topology. Do not update this
file with current claims, model roles, plans, handoffs, verdicts, or next
actions.

See `AGENTS.md` and `PROJECT_GOVERNANCE.md` for the active collaboration model.
