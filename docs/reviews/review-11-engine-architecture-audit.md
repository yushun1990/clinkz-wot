# Review 11 — Engine architecture on master

**Scope.** Independent audit for Owner review of [master at d6a4c86b2629a930b5337913844d14a8fd3cfcf7](https://github.com/yushun1990/clinkz-wot/tree/d6a4c86b2629a930b5337913844d14a8fd3cfcf7). The criteria are the project's enduring goals and the W3C interaction and TD models. Findings below record observed behavior, the strength of the evidence and the kind of decision each warrants. [Project goals](https://github.com/yushun1990/clinkz-wot/blob/d6a4c86b2629a930b5337913844d14a8fd3cfcf7/docs/architecture/00-system-goals-and-context.md) · [WoT Architecture 1.1](https://www.w3.org/TR/2023/REC-wot-architecture11-20231205/) · [Thing Description 1.1](https://www.w3.org/TR/2023/REC-wot-thing-description11-20231205/)

**Assessment.** Master can consume and expose Things through real HTTP and MQTT I/O. More than one logical instance can use common prepared meaning or native infrastructure while retaining its own authority, calls and results. HTTP finite Read demonstrates checked reuse across different endpoints. Caller-owned finite Read and continuing Action execution also work. Each result has a narrower boundary than “the Engine is portable and compiles a Thing once.”

The first pass reproduced three independent failures. A Consumer refuses the standard paired TD context, a Producer publishes a Property with no Forms, and continuing Action preparation can discard the only usable Query alternative. Aggregate Action work also begins before its Engine allowance is checked (F1–F3, F5).

**Second-pass judgment.** Generic Consumer Planning can exclude a third-party implementation before its compiler is called (F12). HTTP already correlates shared-listener input to its original route lease, which narrows the finite recipient question (F4). A capacity-backed finite Producer holding an exchange cannot poll native close with insufficient `QueueOperations` credit (F10). Even with full credit, an exchange deadline can close its participant and revoke the published Thing on reconciliation (F15). On a healthy MQTT session, one Thing's completed, unacknowledged emission keeps the shared writer occupied and blocks a second Thing (F16). F7 and F9 extend existing findings with checks at the first native effect and at an empty receive. F13–F14 distinguish working adapters from public names without execution callers.

**Performance assessment.** Finite Consumer call capacity and physical services can already be shared independently of the logical instance count. Source preparation still scales with qualified mappings, and association construction repeats work even when the mapping set is identical. A composed Producer on a shared default Gateway bank reserves at least 16 MiB of temporary quota per staged exposure and retains preparation records after commit (F17). The audit traces these costs alongside payload validation, service-wide progress and result retirement (F18–F20). The archived 10,000-instance study measured an older HTTP Consumer layout. Its measurements are identified by revision. [Cost by execution path](#cost-by-execution-path) · [Recorded measurements](#what-the-recorded-measurements-establish)

### F1. The semantic resolver refuses the standard TD compatibility context

**Implementation defect · High · reproduced · correction.** TD 1.1 specifies the 2019 context followed by the 2022 context when TD 1.0 Consumers may be present. The library exposes that exact combination. The resolver recognizes either URI only while its seed flag is clear. It rejects the second URI, and finite selection eventually reports an unsupported operation. The project can generate a TD that its own HTTP Consumer cannot prepare. Arbitrary remote context retrieval is a separate policy decision. [TD 1.1 §5.3.1.1](https://www.w3.org/TR/2023/REC-wot-thing-description11-20231205/#thing) · [context builder](https://github.com/yushun1990/clinkz-wot/blob/d6a4c86b2629a930b5337913844d14a8fd3cfcf7/td/src/components/context.rs#L94) · [resolver](https://github.com/yushun1990/clinkz-wot/blob/d6a4c86b2629a930b5337913844d14a8fd3cfcf7/td/src/semantic.rs#L399) · [selection error handling](https://github.com/yushun1990/clinkz-wot/blob/d6a4c86b2629a930b5337913844d14a8fd3cfcf7/planning/src/open_consumer.rs#L785)

**Control.** Prepare one NoSec, read-only integer Property named `level` with an absolute loopback HTTP Form. The 2022 context alone succeeds. Set only `@context` to the serialized result of `Context::new().with_1_0_compatibility()` and the same public registry, compiler and bank return `UnsupportedOperation`. ### F4. Finite dispatch trusts the Binding for original native recipient attribution

**Unresolved architectural question · Medium assurance priority · confirmed trust boundary, no demonstrated misdelivery · further investigation only for a supported case that crosses it.** The finite SPI gives the Binding the original captures, native matching and exclusive reply. Managed staging verifies the participant's readiness and coverage. Servient checks the driving issuer and ingress gate, requires a single candidate, finds the current logical incarnation and behavior, checks data and permission, then fences the callback and delivery. The lookup takes the candidate's instance key as supplied. An incorrect native attribution would violate the Binding contract. The source establishes that dependency. It supplies no example of a conforming attribution that sends a request to the wrong Thing. ### F5. QueryAllActions performs Engine work before checking its work allowance

**Implementation defect · Medium · confirmed by source · correction.** The managed dispatch calls the Binding's aggregate setup, obtains its inventory, then builds a vector of handles. For each native reference it searches the Servient invocation store. Only afterwards does `query_raw_actions` consume the Engine's `HandlerSteps` allowance. ## Performance and scalability on master

A Thing count alone predicts little. One prepared meaning can serve many qualified mappings. An exact mapping can serve many logical associations. An association can exist without a call slot, an open connection or a subscription. Conversely, a single Thing can describe many mappings, run continuing work, and leave several generations of results and native cleanup outstanding. The relevant peak is the set of owners alive **at the same time**. Count shared physical definitions, banks and services once each, and count the references, authority and obligations attached to each recipient separately. [Prepared operations](https://github.com/yushun1990/clinkz-wot/blob/d6a4c86b2629a930b5337913844d14a8fd3cfcf7/planning/src/producer_composition.rs#L130) · [Consumer association](https://github.com/yushun1990/clinkz-wot/blob/d6a4c86b2629a930b5337913844d14a8fd3cfcf7/servient/finite/src/consumer.rs#L1475) · [Producer work and result owners](https://github.com/yushun1990/clinkz-wot/blob/d6a4c86b2629a930b5337913844d14a8fd3cfcf7/servient/finite/src/producer_capacity.rs#L156)

The costs below are source-derived for the audited master unless a measurement revision is given. A work credit is permission to attempt a bounded step. A byte reservation removes quota from an account. Requested live heap counts allocator layouts still owned, cumulative allocation traffic counts every request, and RSS includes allocator and process pages. None measures exclusive CPU time. Time spent waiting for an available lane, a peer or cleanup credit belongs to the caller’s latency even when the Engine does little computation. [Account representation](https://github.com/yushun1990/clinkz-wot/blob/d6a4c86b2629a930b5337913844d14a8fd3cfcf7/core/src/host_accounts.rs#L13) · [Measurement boundaries](https://github.com/yushun1990/clinkz-wot/blob/d6a4c86b2629a930b5337913844d14a8fd3cfcf7/tools/multi-instance/README.md#L70)

For a memory estimate, start with distinct semantic and native definition bytes, qualified mapping records, association entries, quota banks, provisioned pools and physical service/lease backing. Under load, add the simultaneously occupied call, continuation, payload, queue, connection and retiring-result owners, including any original generation they still pin. During admission, account separately for temporary allocations and reserved headroom. A cost per logical Thing is meaningful only after fixing these choices.

### F19. Structured JSON validation revisits the encoded object for each described field

**Unresolved architectural question · Medium for wide structured payloads · confirmed traversal, unmeasured CPU cost · assess the cost of the value-access contract across codecs.** Core asks for one named property at a time. The JSON adapter starts a deserializer on the same borrowed object for each request and scans through the last key, including after a match, to detect duplicates. For a valid object with `d` described fields and `b` encoded bytes at that level, this path can traverse order `d × b` bytes. Nested objects add their own traversals. Comparable-width fields can therefore give quadratic work as an object widens within the declared ceiling of 32 properties, 64 schema nodes and depth eight. Each validated payload incurs its own traversal even when its schema is already compiled and shared. Borrowing raw values avoids holding a second decoded object tree. Checking required fields and rejecting duplicates are semantic obligations. The repeated scans follow from this accessor/codec pairing. Root Property collections use a different member-selection loop, and other `ValueAccess` implementations can supply different lookup costs. The existing allocation traces establish temporary backing and release on their examples, with no exclusive CPU or fleet-throughput measurement.
