# Bounded URI-variable execution

This increment implements finite TD-selected HTTP Consumer Property Read/Write
using source-independent variable meaning, pure native target resolution and
fresh actual-destination authority. It supersedes the former blanket declaration
refusal only for this qualified facet. Shared responsibility belongs to
[TD](../spec/td.md), [Core](../spec/interaction-core.md#uri-variable-execution),
[Planning](../spec/planning.md#uri-variable-preparation),
[Binding SPI](../spec/binding-spi.md#dynamic-native-destinations) and
[runtime safety](../spec/runtime-safety.md#resolved-consumer-destinations).

The [real HTTP tests](../../protocol-bindings/protocols/http/tests/uri_variables.rs)
exercise:

- One prepared definition, two actual ports, two independently authorized logical
  instances and retained earlier results. Source TD/compiler/registry owners are
  dropped before execution; changing the destination constructs no definition.
- Thing/affordance declaration precedence; complete effective unused-schema
  qualification; shared integer bounds, Unicode lengths and boolean values;
  percent/UTF-8 encoding, query and continuation expressions.
  Root-query templates exercise fixed and variable ports with actual HTTP
  origin-form serialization, retaining the originally authorized absolute URI.
- Missing, extra, unused, duplicate, malformed, oversized and out-of-schema
  values; unsupported expression/schema assertions; expanded native port and
  destination-capacity refusal; actual-destination permission denial before I/O.
  Refused Writes return their original payload.
- Reuse of the same common owner across differently qualified native literals;
  changed variable schema meaning refuses reuse without rebuilding that owner.
- Engine Consumer-to-Producer verified HTTPS/Basic through a dynamic Consumer
  path and a completely qualified static Producer. Wrong actual audiences and
  raw substituted destinations/grants refuse before native I/O/credentials.
- Successful Write, subsequent in-flight permission loss, original cancellation,
  unknown remote effects, retained late Read output and original-account release
  only after settlement disposal. No automatic replay follows a refusal.
- Complete Producer qualification refusing dynamic mappings and unused retained
  declarations. No dynamic Producer advertisement is introduced.

Core unit tests separately use RFC simple/query examples and the shared scalar
schema evaluator. Existing static, response, security, allocation and downstream
fixtures remain regression evidence within their original scope. Exact commands
and reviewed revision belong to the PR/CI, not a mirrored repository run log.

The [restricted Read regression](../../protocol-bindings/protocols/http/tests/restricted_form_selection.rs)
checks the separately registered literal-only compiler profile with Thing- and
affordance-level declarations. Default selection skips a templated first Form
and executes the static alternative over HTTP; explicit static selection also
executes. Explicit template selection, with or without supplied values, refuses
before an outbound request is constructed. All original accounts release after
shutdown. Dynamic compilation remains eligible for the modern finite owner that
implements validation, resolution and actual-destination authorization.

Limits: eight effective declarations, 32 bytes/name, 128 bytes/value and 256
template bytes. Supported types are strings, canonical base-ten i64 integers and
booleans; supported constraints are the existing integer boundaries and Unicode
string lengths. Number/null/untyped variables, enum/const/pattern/format and other
unimplemented assertions refuse. Supported expressions are simple, form-style
query and query-continuation with ASCII literals and ASCII alphanumeric/underscore names. Every
referenced operand is required; defaults supply no values. HTTP fixes scheme and
IP host and supports changing port/path/query. The default destination bound is
64 bytes; an explicitly configured modern finite mapping may use up to 256.
Audience services remain exact-target services, not implicit origin-wide grants.

Relative templates against `base`, dynamic scheme/host, reserved expansion,
prefix/explode/composite expressions, dynamic Property Producer matching,
general caller-supplied variables for continuing Action/notification/collection
execution and portable dynamic I/O remain
unsupported. The portable borrowed view retains variable meaning and its current
Read representation explicitly refuses dynamic support. A Thing may represent
many physical/virtual resources; neither this increment nor the shared boundary
requires one device, connection, cache or native artifact per logical Thing.
No general RFC/schema conformance, production qualification, package/gate or
milestone acceptance is claimed.
Existing qualified native Action continuation-ID mappings retain their separate
profile and original invocation authority; this increment does not replace them.
