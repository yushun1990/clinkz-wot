# Deprecated Project State Carrier

`PROJECT_STATE.md` is no longer an active continuation or remote-state cache.

Fresh task sessions reconstruct current state from the fetched default branch,
`PLAN.md`, relevant authoritative documents, open pull requests or task
branches, code, tests, and CI. Remote facts are re-read from GitHub when they
matter. The next action is derived from those sources rather than stored here.

This path is retained only because historical review and transition evidence
may reference it as part of an exact repository topology. Do not update this
file with current status, blockers, remote observations, stopping points,
model roles, or next actions.

See `AGENTS.md` and `PROJECT_GOVERNANCE.md` for the active recovery and
collaboration model.
